# Kolam-designs

Kolam Weaver is a single-file browser app for building pulli kolam patterns — the dot-grid threshold drawings traditional in Tamil homes. Click dots to wake them; whenever four neighbouring dots are all active, a thread loops around them automatically, the same way a real kolam line always wraps around a dot rather than through it.

Features
Adjustable dot grid, 5×5 up to 11×11
Click-to-toggle dots with live auto-weaving
Four preset generators that scale to whatever grid size is selected:
Diamond bloom — solid filled rhombus
Square frame — hollow two-dot-thick border
Cross bloom — filled plus-shape through the center
Symmetric mandala — one quadrant randomized, then mirrored
Scatter dots, Wake all, and Clear for quick starts
Botanical-dark visual style with mango-leaf corner flourishes
Installation

No installation or build step required. Download kolam-weaver.html and open it in any modern browser.

bash
open kolam-weaver.html
Usage
Open kolam-weaver.html in your browser.
Drag the grid slider to choose a size (5×5–11×11).
Click dots to activate them, or use a preset button (Diamond bloom, Square frame, Cross bloom, Symmetric mandala) to auto-generate a pattern sized to the current grid.
Use Scatter dots for a random start, Wake all for the full dense weave, or Clear to reset.
Roadmap
Animated draw-on, so the thread reveals itself stroke by stroke
True rotational/mirror symmetry mode (one click updates all four quadrants)
Save-as-image / export button
